# Padrão de Layout Interno Rocket

Use este padrão ao criar ou revisar qualquer página interna ou módulo interno.

## Página interna

- Botões superiores sempre verdes, redondos e alinhados à direita.
- O botão ativo usa o destaque verde mais claro.
- O breadcrumb mostra página principal, página interna e módulo atual.
- O último item do breadcrumb fica em negrito.

## Módulo interno

- Todo o conteúdo fica dentro de um contêiner claro com bordas arredondadas.
- Deve existir um pequeno espaçamento entre os botões superiores e o contêiner.
- Tabelas ficam dentro do contêiner claro, com fundo interno esverdeado e bordas quadradas ou levemente arredondadas.
- Um segundo painel de botões do módulo fica dentro do contêiner, em cor escura e alinhado à esquerda.
- O conteúdo deve manter espaçamento confortável em desktop e celular.

## Evolução

Novas orientações do usuário podem ser adicionadas a este documento e passam a fazer parte do padrão.
