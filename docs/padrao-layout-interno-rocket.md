# Padrão de Página Interna Rocket

Use este padrão ao criar ou revisar qualquer página interna ou módulo interno.

## Navegação obrigatória`r`n`r`n- O link de navegação deve estar sempre presente.`r`n- O último item representa a página ou módulo atual e fica em negrito.`r`n- A navegação por botões de módulos internos deve atualizar o endereço do módulo, mesmo quando o conteúdo é exibido na mesma estrutura de página.`r`n- Cada módulo interno deve possuir um caminho identificável no link.`r`n`r`n## Página interna

- Botões superiores sempre verdes, redondos e alinhados à direita.
- O botão ativo usa o destaque verde mais claro.
- O breadcrumb mostra página principal, página interna e módulo atual.
- O último item do breadcrumb fica em negrito.

## Módulo interno

- Todo o conteúdo fica dentro de um contêiner claro com bordas arredondadas.
- Deve existir um pequeno espaçamento entre os botões superiores e o contêiner.
- Tabelas ficam dentro do contêiner claro, com fundo interno esverdeado e bordas quadradas ou levemente arredondadas.
- Um segundo painel de botões do módulo fica dentro do contêiner, em cor escura e alinhado à esquerda.
- O conteúdo deve manter espaçamento confortável em desktop e celular.`r`n- Os botões dos módulos internos seguem sempre o formato arredondado.`r`n- Os contêineres dos módulos não precisam repetir títulos que já estejam identificados no breadcrumb.

## Nome do padrão`r`n`r`nQuando o usuário solicitar “conferir o Padrão de Página Interna”, revisar todos os itens deste documento em qualquer página existente ou nova.`r`n`r`n## Evolução

Novas orientações do usuário podem ser adicionadas a este documento e passam a fazer parte do padrão.
